# Secure File Sharing & Query Service

## Branches
- backend → Java + APIs + security
- frontend → React UI

## Features (planned)
- File upload (REST, OAS 3.0)
- GraphQL querying
- AES-256 encryption + SHA-256 integrity
- mTLS authentication (PKI, Let’s Encrypt)
- HTTP/3 transport
- Opaque token access control
